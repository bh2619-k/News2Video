# Features:
- Scrapes articles from Yahoo News & Mirror.co.uk
- Converts text and images into video
- Adds automatic voiceovers

# Usage:

```bash
pip install -r requirements.txt
python main.py --url "news url" \
               --lang "optional" \
               --fps "optional" \
               --width "optional" \
               --height "optional"
```
